# 介面約定（五條線共用，改這份要先問主 session）

A～E 五個 session 同時在 `huangquan-village/` 裡工作，各自只寫自己的檔案。這份約定讓大家接得起來。
設計依據：`docs/企劃書.md`（第 11～15 節是最新決定，與前面衝突時以後面為準）、設計圖 https://claude.ai/artifact/9AvhYengs1T25dgqPngqnW 。

## 共同原則

- 盡量全用劇中角色；稱呼一律「業鏡羅漢」，不寫「老闆」。
- 語彤實習月老造型：黑色鮑伯頭、無眼鏡、胎記點亮片、白綠漢服、綠流蘇髮飾（參考 `refs/yutongh-normal.webp`）。
- 不照原劇章節；目標是「幫助人數」。
- 誰都不要 git commit／push（目前不是 git repo），也不要改別人的檔案。
- 對外頁面不寫製作方法；頁尾保留「非官方粉絲作品」與原作出處。

## 資料檔格式

全部是一般 script（不用 module），掛在 `window.HQ` 上，`index.html` 依序載入：

```js
window.HQ = window.HQ || {};
HQ.buildings = [ ... ];
```

### HQ.buildings（B）
```js
{ id: "yakiniku", name: "黃泉燒肉店", cat: "special" | "shop" | "food" | "home" | "deco" | "road",
  size: [2, 2],            // 格數 [寬, 高]
  cost: 1200, upkeep: 60,  // 冥紙
  merit: 0,                // 蓋的時候要花的功德
  price: 40,               // 客人每次使用付的冥紙（Lv1）
  quality: 10, appeal: 10, // 原作的品質、魅力
  maxLv: 10,
  traits: { 美味: 5, 安心: 2 },   // 加的街區特徵點數
  serves: ["eat", "reincarnate"], // 滿足哪些心願（見 HQ.wishes）
  unique: true,
  unlock: { resident: "lee" } | { rank: 2 } | { helped: 30 } | { start: true },
  sprite: "art/buildings/yakiniku.png" }
```

### HQ.jobs（B）
`{ id, name, line: "服務" | "引導" | "巡守" | "技藝" | "術法" | "特殊", growth: { 魂力, 膽量, 手藝, 定力, 靈力, 福報 }, from: ["新魂"], cost: 功德, medals: 0, effect: "..." }`
六項屬性名稱固定：魂力（HP）、膽量（攻擊）、手藝（攻擊次數）、定力（防禦）、靈力（法術）、福報（寶箱）。

### HQ.traits / HQ.ranks（B）
- `HQ.traits = ["美味","思念","緣分","儀容","藝術","娛樂","安心","香火","秩序","魔氣"]`
- `HQ.ranks = [{ star: 1, popularity: 300, ... }, ...]`；位階 `HQ.titles = ["實習月老","見習月老","月老"]` 與升階條件（幫助人數）。

### HQ.chars（C）
```js
{ id: "yutong", name: "語彤", job: "實習月老", start: true,
  movein: { order: 0 } | { traits: { 美味: 30 }, popularity: 200 } | { request: "maoguai" },
  brings: "tattoo",          // 入住時帶來的建築 id
  sprite: "art/chars/yutong.png", face: "art/chars/yutong-face.png",
  lines: [ ["EP3-13", "我想你教我愛戀文印……"] ] }
```
角色 id 沿用轉珠遊戲 `huangquan-puzzle/art/vn/` 的代號（yutongh→用 `yutong`、lee、yuelao、guanyin、xiaoyu、dabao、mimi、baimei、huji、jiuwei、du、xiaomi、huatuo、no7、yangzi……），沒有的自己取拼音。

### HQ.requests（C）
`{ id, char: "maoguai", ep: "EP1-01", title, need: [{ building: "..." } | { trait: "安心", min: 50 } | { resident: "heitang" } | { action: "dream" }], reward: { merit, helped: 1, movein: true }, lines: [[ep, 句子]] }`

### HQ.events、HQ.calendar、HQ.maps（C）
- events：`{ id, when: { month?, rank?, random?: 機率 }, title, lines, effect }`
- calendar：12 個月的固定事件（清明、中元、愛神祭、季末觀音評定、12 月年度評定）
- maps：出征地點 `{ id, name, open: { rank } | { start: true } | { month: 7 }, enemies: [...], boss, helpers: [...] }`

### HQ.wishes（B）
亡魂心願種類：`eat`、`sweets`、`dream`（托夢）、`hair`、`tattoo`（文印）、`rest`、`shop`、`art`、`reincarnate`……B 定清單，C 的委託和 A 的泡泡圖示都用這份。

## 素材規格

- **格子**：一格 32×32 px，3/4 俯視、正交格（開羅式，不是等角菱形）。遊戲內 2 倍或 3 倍整數放大，`image-rendering: pixelated`。
- **角色走路圖（D）**：`art/chars/<id>.png`，64×128 透明 PNG：2 欄（兩格步伐）× 4 列（下、左、右、上），每格 32×32，腳底貼格子底邊。
- **頭像（D）**：`art/chars/<id>-face.png`，64×64。
- **一般亡魂（D）**：`art/chars/soul-1.png`～`soul-8.png`，同走路圖規格。怪物：`art/chars/mob-<id>.png`。
- **建築（E）**：`art/buildings/<id>.png`，寬 = 格數 × 32，高可以往上超出（屋頂），底邊對齊佔地的最後一列。附 `art/buildings/index.json`：`{ "<id>": { "w": 64, "h": 88, "size": [2,2] } }`。
- **地面（E）**：`art/tiles/ground.png` tileset（32×32 一格），含草地、石板路、土路、河水（可動畫 2 格）、河岸邊緣、彼岸花叢；附 `art/tiles/index.json` 標每格用途。
- **調色盤**：`art/palette.json`，所有像素圖量化到這組顏色。
