# 數值平衡（B 線）

## 怎麼跑

這台 Mac 沒裝 node，`run.sh` 會借 ChatGPT／codex 內建的 node：

```bash
balance/run.sh                         # 20 局 × 3 年，印里程碑中位數＋代表局季報
balance/run.sh --seed 1 --verbose      # 單局，逐週紀錄（蓋了什麼、誰入住、評定）
balance/run.sh --years 5 --seeds 10
balance/run.sh --variant lazy          # 不升級、不辦活動、不轉職
balance/run.sh --variant greedy        # 蓋房子不留預備金
balance/run.sh --variant nocombo       # 不湊緣分組合
balance/run.sh combat                  # 各出征地圖的戰鬥檢查
```

`result-*.txt` 是目前這版數值的輸出。

## 模型

`sim.js` 直接載入 `data/*.js`，所有常數都讀 `HQ.balance`、`HQ.review`、`HQ.ranks`、`HQ.titles`（`data/ranks.js`），沒有另外藏一份數字。引擎照同一份公式實作，結果才會接近。

- **時間**：1 週＝14 班列車，1 月＝4 週（跟引擎 CFG 一樣）。
- **來客**：每班 `0.2 + 人氣/1600`，再加候車亭 +0.15、王牌引渡貓每隻 +0.08；小數當機率，每週最多 40 位。
- **亡魂**：錢包 `70 + 人氣×0.06`（±30%），心願 1～3 個，從已解鎖的心願抽（權重在 `HQ.wishes`）。先找能滿足心願的店（依魅力抽），錢夠就付 `price(Lv)`、安心度 `+27×品質係數`；剩下的次數（最多 5 間）45% 機率隨便逛，`+6×品質係數`。品質係數＝`品質(Lv)/25`，夾在 0.5～1.4。
- **離開**：心願全滿足且 `亂數×100 < 安心度` → 安心了：30% 想留下（要有空房，且一般街坊少於 `genericCapByStar[☆]`），其餘送行投胎（幫助 +1、功德 1，有燒肉店 ×2，「最後一餐」組合再 ×1.3）。沒滿足的人帶著遺憾離開，人氣 −0.3。
- **文印**：每週有求文印的人兩兩成組，上限＝位階 `wenyinPerWeek`（1/2/3）＋店 Lv4/7/10 各 +1＋杜氏分店 +1＋紅線大街 +1。一組幫助 2 人、功德 +30（紋身師那一份，劇中行情）。
- **托夢**：照相館每次街區代付 10 功德（劇中行情），幫助 +1、安心 +40。
- **人氣**＝累積值＋Σ建築魅力×0.5。累積值來自光顧（0.06×品質係數）、幫助（0.4/人）、活動、評定、愛神祭。
- **上班**：要人顧的店沒人顧，品質 ×0.7。主要角色顧自己的店 ×1.3，一般街坊 ×1.1。
- **觀音評定**：只看當季表現（人氣增加、送行、文印、托夢、委託、打王），及格分看目前 ☆（`target.byStar`）。☆ 在每季評定時檢查，一次最多升 1 星。位階在 12 月看幫助人數。
- **玩家 AI**：照 `PLAN` 順序蓋（先吃住、再名店、再裝飾和重複的店），留 600＋一個月維持費當預備金；錢多就升級來客最多的店；功德先拿去擴地，再辦活動（每季 7 次），一般街坊入住 2／8／18 個月後轉職。每季出征一次，隊伍等級估 `3 + 0.9×月數`。
- **入住**：直接讀 C 線 `data/chars.js` 的 movein（kind resident）。模擬判斷不了的條件：request 當作「完成 8 件委託後成立」、flag 不成立、month 是外賓不算。玩家會看「誰只差特徵」，先蓋最划算能補那個特徵的一般建築（`chaseTraits`）。沒有 chars.js 時用企劃書第 11 節的估計順序。
- **委託**：讀 `data/requests.js` 的件數與平均獎勵（目前 36 件、平均功德約 66），假設第 2 個月起每月完成 1 件。

## 戰鬥（`combat.js`）

4 人隊伍（1 位主要角色＋刀鋸／引渡貓／術法各 1）、推薦等級，期望值計算：每張地圖都打得過王（剩血 13～54%），低 3 級打不過王（第三王國的瘟疫是中王，低 3 級也能過）。推薦等級：刀鋸地獄 8、高熊市 11、陽間海邊 14、心堀江 16、古神遺跡 22、魔界第二王國 30、第三王國 42、北境 58。

## 已知問題／給引擎的建議

- 第一年「不滿%」偏高（70～80%）：初期店少，心願常常沒有店能滿足；而且為了湊大寶的思念 25，模擬玩家第一年蓋了十幾盞燈籠而不是店。已經請 C 把門檻下修（大寶 思念 15、白妹 儀容 10、狐姬 娛樂 20、七號 美味 45），改了之後第一年會輕鬆一點。嫌太苦也可以把 `startPeace` 調到 20。
- 緣分組合在模擬裡影響小（品質係數上限 1.4 很快就碰到）。引擎如果想讓組合更有感，可以讓組合另外加人氣，或把 `qfMax` 提到 1.6。
- 後期功德會累積（Y3 約 3,000～4,000）。主要出口是轉職和名店升級（功德 15×Lv）。如果覺得太多，先調低 `HQ.review.meritPerScore`。
- 冥紙變負：建議引擎允許短暫負值，但不能蓋、不能出征，連續 2 個月負值觸發觀音提醒事件。
- 位置效果（裝飾光環、組合距離、慰靈犬範圍）模擬沒擺位置，用平均值估。
