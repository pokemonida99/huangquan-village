# 任務：潤飾《三途川物語》的劇情台詞

這是一款手機經營遊戲（玩法像開羅《冒險村物語 2》），角色來自 IG 短劇《黃泉燒肉店》。很多台詞是從劇中剪下來的原句，玩家很可能**沒看過劇**、也**沒玩過這款遊戲**。請你逐段檢查並修改，讓每一段：

1. **前後邏輯通順**：誰在跟誰說話、為什麼說、回話接得上。沒有前因的回話、指涉不明的「他／她／那個」，要補一句交代，或改掉。
2. **沒看過劇的人也看得懂**：第一次出現的人物、地方、道具，用一句旁白或對話自然帶過身分（只能用下方「角色表」寫到的資料）。
3. **時空切換要標示**：回想、托夢、吃下遺願馬卡龍看到的幻境、念信、夢境、換地點，前面要有一句旁白，格式是 `[null, "【標示】可接一句說明", "字卡"]`，例如 `【回想：七十多年前，倒塌的米莊】`、`【托夢：陽間，爸爸的夢裡】`、`【陽間・月老廟】`。已經有的保留，不清楚的改清楚。
4. **口吻符合角色**（看角色表的 desc）。句子要像真人講話，短一點，不要書面腔、不要 AI 腔。

## 世界觀（遊戲裡的設定）
- 地點：三途川岸邊的街區。剛過世的亡魂每天早晚搭列車到這裡，由引渡貓帶路。
- 語彤：剛拜月老為師的實習月老，是這條街的主角，玩家跟著她經營街區、幫助亡魂。月老是她的師傅。
- 冥紙：亡魂付給店家的錢。功德：做好事累積的點數。
- 黃泉燒肉店：業鏡羅漢的店。「遺願馬卡龍」吃下去會看到自己完成心願的幻境，放下執念後去投胎。
- 托夢照相館：大寶的店，亡魂拍照就能托夢給陽間的人（頭七免費，平常要功德）。
- 月老紋身店：「愛戀文印」是替兩個相愛的靈魂做的紋身，可以跨越輪迴。
- 觀音菩薩每季來巡察。出征＝帶街坊去別的地方打倒作亂者。陽間＝活人的世界。

## 規則
- 用**繁體中文、台灣用語、全形標點**。不要中國用語（例如 視頻、質量、信息、搞定）。
- **絕對不可以出現「老闆」兩個字**（包含老闆娘），業鏡羅漢一律叫「業鏡羅漢」。
- **不要新增角色表沒寫的設定**（身世、關係、能力、往事）。不確定的就不要寫，寧可用中性的旁白帶過。
- 每一句是 `[集數, 句子, 說話者]`：
  - 集數不是 null 的是**劇中原句**。能不改就不改；**如果你改了字（包含刪字、加字），把集數改成 null**。原句一字不改才保留集數。
  - 你新寫的句子，集數一律 null。
  - 說話者：主要角色用角色表的 id（例如 "yutong"、"lee"）；旁白用 "字卡"；路人照原本寫的稱呼（例如 "機車騎士"）。不要讓這段沒出現的主要角色突然開口。
- 可以：調整順序、刪掉接不上的句子、補旁白、補一兩句讓對話接上。
- 每段長度不要超過「原本句數 × 1.5 ＋ 3」。
- 不要改每段的 key。

## 輸出
讀 `in-X.json`，把結果寫成同資料夾的 `out-X.json`（X 是同一個字母），**必須是合法 JSON**：
```json
{ "scenes": { "<key>": [[null, "句子", "字卡"], ["EP1-03", "原句", "mimi"]] },
  "notes":  { "<key>": "一句話說明改了什麼（沒改就寫「未改」）" } }
```
`scenes` 要包含輸入裡**每一個** key（沒改的照抄）。只寫檔案，不要做其他事。
